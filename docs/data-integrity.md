# قرارداد صحت داده

هر قیمت قبل از ورود به مقایسه چهار کنترل مستقل دارد:

1. **جهت:** `ask` قیمت خرید کاربر و `bid` قیمت فروش کاربر است؛ نام فیلد endpoint به‌تنهایی کافی نیست و باید با UI یا preview سفارش تطبیق داده شود.
2. **واحد:** همهٔ قیمت‌ها فقط پس از تبدیل مستند به «تومان برای هر گرم طلای ۱۸ عیار» نمایش داده می‌شوند.
3. **زمان:** timestamp منبع باید معتبر و با زمان دریافت هم‌فاصله باشد. endpoint بدون زمان منبع قرنطینه می‌شود.
4. **هزینه:** اگر fee داخل قیمت نهایی نیست، نرخ خرید و فروش و VAT همان fee باید جداگانه کسر شود.

کیفیت quoteها:

- `COMPARABLE`: دوطرفه، هم‌زمان، واحد و هزینه کامل؛ مجاز برای موتور فرصت.
- `QUARANTINED`: قیمت نمایش داده می‌شود اما وارد سیگنال نمی‌شود.
- `REFERENCE_ONLY`: فقط نرخ مرجع؛ هر دو سمت اجرایی ناشناخته‌اند.
- `UNAVAILABLE`: پاسخ رسمی و معتبر نداریم.

ذخیره‌های محافظه‌کارانهٔ پیش‌فرض برای یک سیکل:

- لغزش خرید: ۰٫۱٪
- لغزش فروش: ۰٫۱٪
- بازتوازن: ۰٫۰۳٪ ارزش میانی
- هزینهٔ تسویه: ۲۰٬۰۰۰ تومان
- VAT: ده درصدِ مبلغ کارمزد، نه ده درصدِ اصل طلا
- حداقل سود خالص: ۱۰۰٬۰۰۰ تومان
