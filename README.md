# زرگَرد (ZarGard) — Android

نسخهٔ بومی Android برای پایش اختلاف قیمت طلای ۱۸ عیار میان پلتفرم‌های ایرانی؛ با رابط فارسی RTL، کنترل کیفیت quote و محاسبهٔ سود خالص پس از همهٔ هزینه‌ها.

> این نسخه در مرحلهٔ پژوهش و paper monitoring است. اجرای خودکار معامله تا زمان تأیید API معاملاتی، پیش‌نمایش سفارش و مجوز هر پلتفرم عمداً خاموش است.

## آنچه اکنون کار می‌کند

- رابط مدرن Jetpack Compose با طراحی سبز تیره/طلایی و ناوبری چهاربخشی
- دریافت مستقیم و read-only چند endpoint عمومی رسمی
- پایش استراتژی اصلی موجودی دوطرفه روی پلتفرم‌های طلای ۱۸ عیار ایران
- نمایش صریح پنجرهٔ غربال ۷۲ ساعته و شرط برگشت جهت همان جفت
- جداسازی صریح `ask`، `bid` و `reference-only`؛ از تک‌نرخ bid/ask جعلی ساخته نمی‌شود
- قرنطینهٔ quoteهای فاقد timestamp یا fee تأییدشده
- محاسبهٔ فرصت با کسر کارمزد، VAT کارمزد، لغزش دو سمت، بازتوازن و تسویه
- آستانهٔ بدبینانهٔ پیش‌فرض: `100,000` تومان سود خالص
- نمایش پوشش هماهنگ با وب: ۵۶ سکوی شناسایی‌شده، ۳۱ collector پیاده‌سازی‌شده و ۱۸ مورد بدون feed معتبر
- CI برای اجرای unit test و ساخت debug APK در هر push

## نصب روی موبایل

آخرین نسخهٔ آزمایشی را از لینک زیر دریافت کنید:

**[دانلود مستقیم ZarGard Android 0.7.2 Beta](https://github.com/pouriaquant91/gold-arbitrager-android/releases/download/android-v0.7.2/ZarGard-android-0.7.2-beta.apk)**

نسخهٔ ۰٫۷ تترگلد را از مسیر فعال حذف کرده و رابط را روی مقایسهٔ مستقیم طلای ۱۸ عیار، پایش برگشت جهت و مدل موجودی دوطرفه متمرکز می‌کند. ظاهر Emerald Luxury، تم روشن/تیره/سیستم، سبک Navy و قفل اثر انگشت حفظ شده‌اند.

## نسخه PWA

نسخه نصب‌پذیر وب با همین برند در [ریپازیتوری ZarGard PWA](https://github.com/pouriaquant91/zargard-pwa) نگهداری می‌شود و از آدرس [zargard-pwa.ihamedcs.chatgpt.site](https://zargard-pwa.ihamedcs.chatgpt.site) قابل اجراست.

فایل APK را روی گوشی باز کنید و در صورت درخواست Android، اجازهٔ نصب از همین مرورگر یا File Manager را فعال کنید. این build با کلید debug امضا شده و برای تست شخصی است؛ نسخهٔ انتشار نهایی بعداً با keystore اختصاصی و Play Integrity آماده می‌شود.

## مدل استراتژی

ربات قرار نیست طلا را برای هر معامله از یک سکو به سکوی دیگر منتقل کند. مدل هدف، موجودی دوطرفه است:

1. در هر سکوی منتخب مقداری ریال و طلا نگهداری می‌شود.
2. خرید و فروش در دو سکو هم‌زمان انجام می‌شود.
3. انتقال طلای بین‌سکویی داخل هر سیکل صفر است.
4. ارزش واقعی یک جفت وقتی ثابت می‌شود که جهت اختلاف آن در طول روز چند بار برگردد.
5. بازتوازن موجودی فقط به‌صورت دوره‌ای و با هزینهٔ ازپیش‌کسرشده انجام می‌شود.

جزئیات مدل داده و مسیر سکوهای بدون feed در [docs/data-integrity.md](docs/data-integrity.md) و [docs/feed-discovery.md](docs/feed-discovery.md) آمده است.

## ساخت پروژه

### هماهنگی با Core و PWA

فایل `.zargard/distribution-contract.json` مرجع نسخه و اعداد پوشش مشترک است. CI سازگاری آن با نسخه و اعداد داخل اپ را کنترل می‌کند. مقایسه خودکار با مخزن خصوصی Core پس از تنظیم Secret مشترک `ZARGARD_SYNC_TOKEN` نیز فعال می‌شود.

پیش‌نیازها: JDK 17 و Android SDK 36.

```bash
./gradlew testDebugUnitTest assembleDebug
```

خروجی APK در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## امنیت

- فقط HTTPS مجاز است.
- هیچ توکن معامله، کلید تلگرام یا credential داخل APK نگهداری نمی‌شود.
- endpointهای فعلی عمومی و read-only هستند.
- کلیدها و عملیات معامله در نسخهٔ بعدی فقط در backend امن قرار می‌گیرند.
- هر quote مستقل از در دسترس بودن feed، باید گیت timestamp، جهت، واحد و fee را بگذراند.

## فناوری

- Kotlin + Jetpack Compose + Material 3
- Android Gradle Plugin 9.4 / Gradle 9.6
- `compileSdk` و `targetSdk` 36 (آخرین SDK پایدار)، حداقل Android 8 (API 26)
- بدون SDK شبکهٔ شخص ثالث در MVP؛ فقط `HttpURLConnection` و `org.json`

## ارتباط با پروژهٔ وب

این مخزن کلاینت Android مستقل است. موتور پایش بلندمدت، ثبت مدت فرصت، هشدار تلگرام و ذخیرهٔ تاریخچه در backend پروژهٔ اصلی باقی می‌ماند تا secretها وارد APK نشوند.

در فاز فعلی هشدارها عمداً غیرفعال‌اند: ابتدا Shadow Signal روی حداقل ۷۲ ساعت دادهٔ clean اجرا می‌شود و هر بازهٔ پیوسته پس از دو نمونهٔ متوالی فقط یک ورود حساب می‌شود.
